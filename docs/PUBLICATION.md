# Source publication

The public repository is https://github.com/melloxyz/DCR-Manager . It was published from the original development history, not the separately sanitized clone. The public history therefore retains original commit identities. New commits use the maintainer's GitHub noreply identity. Do not rewrite public history without explicit approval.

The MIT license and third-party notices are present. The default main branch tracks the approved source milestone. Keep feature branches focused, retarget dependency PRs to main and preserve tags. Source milestones are distinct from public binary distribution; see RELEASE-CHECKLIST.md and ROADMAP.md.

Before binary publication, build from the exact public tag, include license notices, verify checksums and clean-machine acceptance, and exclude all runtime state. Never upload old local artifacts under a different tag or commit.
